## S-01. 도서 목록 → 상세 조회

- **관련 기능**: F-03, F-04, F-05, F-07, F-08
- **사전 조건**: json-server 실행 중, db.json에 예시 도서 3권

### 기본 흐름
1. 사용자가 네비게이션에서 [도서 목록]을 클릭한다
2. 목록을 불러오는 동안 "불러오는 중..."이 표시된다
3. 도서 카드가 최신 등록순으로 표시된다 (표지 썸네일·제목·등록일)
4. 표지가 없는 도서는 플레이스홀더로 표시된다
5. 사용자가 도서 카드를 클릭한다
6. 상세 화면에 표지·제목·저자·본문·작성일·수정일이 표시된다
7. [목록으로]를 클릭하면 목록 화면으로 돌아간다

### 예외 흐름
- 2a. json-server가 꺼져 있음 → "목록을 불러오지 못했습니다" + 다시 시도 안내
- 3a. 도서가 0권 → "등록된 도서가 없습니다" + [새 도서 등록] 버튼
- 6a. 주소창에 없는 id 입력 (`/books/999`) → "존재하지 않는 도서입니다" + [목록으로]

## S-02. 신규 등록 → AI 표지 생성 → 저장 (메인 시나리오)

- **관련 기능**: F-09, F-10, F-14 ~ F-21
- **사전 조건**: json-server 실행 중, 조별 OpenAI API Key 보유

### 기본 흐름
1. 사용자가 [새 도서 등록]을 클릭한다 (02 도서등록)
2. 제목·저자·내용을 입력하고 [등록]을 클릭한다
3. 등록된 도서의 상세 화면으로 이동한다 (03 도서상세, 표지는 플레이스홀더)
4. [AI 표지 생성]을 클릭한다 (05 AI표지생성)
5. API Key를 입력하고 품질을 선택한다 ("생성 시 API 비용이 발생합니다" 안내 확인)
6. [생성]을 클릭한다
7. 버튼이 비활성화되고 "생성 중..."이 표시된다
8. 생성된 표지가 미리보기로 표시되고, [이 표지로 저장]을 클릭한다
9. 상세 화면으로 돌아와 새 표지와 갱신된 수정일이 표시된다
10. 목록으로 가면 해당 도서 카드에 새 표지가 표시된다

### 예외 흐름
- 2a. 제목·저자·내용 중 하나라도 공백 → 해당 필드 아래 "OO을(를) 입력하세요", 저장 안 됨
- 2b. 저장 요청 실패 → "등록에 실패했습니다", 입력값 유지 (다시 입력하지 않게)
- 6a. API Key 빈 값 → 요청을 보내지 않고 "API Key를 입력하세요"
- 7a. 생성 중 버튼을 다시 클릭 → 반응 없음 (중복 요청 방지)
- 8a. 401 → "API Key를 확인하세요", 버튼 다시 활성화
- 8b. 429 → "요청이 많습니다. 잠시 후 다시 시도하세요"
- 8c. 네트워크 오류 / 응답에 이미지 없음 → "표지 생성에 실패했습니다"
- 8d. 생성은 성공했으나 저장(PATCH) 실패 → "표지 저장에 실패했습니다", 미리보기 유지(다시 저장 가능)
- 8e. [취소] → 저장 없이 상세로 복귀 (기존 표지 유지)

## S-03. 도서 정보 수정

- **관련 기능**: F-10, F-12, F-14
- **사전 조건**: 도서 1권 이상 존재

### 기본 흐름
1. 상세 화면에서 [수정]을 클릭한다
2. 수정 화면에 기존 제목·저자·내용이 채워져 있다
3. 제목만 바꾸고 [저장]을 클릭한다
4. "수정되었습니다" 메시지 후 상세 화면으로 이동한다
5. 바뀐 제목과 갱신된 수정일이 표시된다 (작성일은 그대로)

### 예외 흐름
- 3a. 제목을 모두 지우고 저장 → "제목을 입력하세요", 저장 안 됨
- 3b. [취소] 클릭 → 변경 없이 상세 화면으로 복귀
- 4a. 저장 실패 → "수정에 실패했습니다", 입력값 유지

## S-04. 도서 삭제

- **관련 기능**: F-13, F-14

### 기본 흐름
1. 상세 화면에서 [삭제]를 클릭한다
2. "정말 삭제하시겠습니까?" 확인창이 뜬다
3. [확인]을 클릭한다
4. "삭제되었습니다" 메시지 후 목록 화면으로 이동한다
5. 목록에서 해당 도서가 사라져 있다

### 예외 흐름
- 3a. [취소] 클릭 → 아무 일도 일어나지 않음
- 4a. 삭제 실패 → "삭제에 실패했습니다", 상세 화면 유지

## S-05. 도서 검색 (부가)

### 기본 흐름
1. 목록 화면 상단 검색창에 키워드를 입력한다
2. 입력할 때마다 제목(·저자)에 키워드가 포함된 도서만 표시된다
3. 검색어를 지우면 전체 목록이 다시 표시된다

### 예외 흐름
- 2a. 일치하는 도서 없음 → "검색 결과가 없습니다"

---

## S-06. 표지 미리보기 후 재생성 (부가, D6 결정 시)

### 기본 흐름
1. S-02의 6~8단계에서, 생성된 표지가 **미리보기**로 표시된다 (아직 저장 전)
2. 마음에 들지 않아 [다시 생성]을 클릭한다
3. 새 표지가 미리보기로 표시된다
4. [이 표지로 저장]을 클릭하면 저장되고 상세·목록에 반영된다

### 예외 흐름
- 4a. 저장하지 않고 화면을 벗어남 → 기존 표지 유지 (미리보기는 버려짐)
